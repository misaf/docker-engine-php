# Security Policy

## Supported versions

Security fixes are provided for the latest release in the `1.x` line. Users should update to the newest available patch release before reporting an issue.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** flow in the repository's Security tab. Include the affected SDK version, PHP version, Engine implementation and version, transport configuration with secrets removed, impact, reproduction steps, and any suggested mitigation.

Private vulnerability reporting is enabled for this repository. Do not open a public issue containing exploit details.
